# 回归清单（试验版 → 正式版整改用）

> 用途：正式版落地计划「阶段 1：建立基线」。先在整改前完整跑一遍，记下每条的实际表现；之后每个整改批次重跑相关的组。
> 规则依据：`芙兰战斗系统说明书_v5.docx`。括号里是说明书的章节号。
> 「结果」列填：1 = 符合 / 0 = 不符（写现象）/ ? = 没测（写原因）。不符的同时记进 `memory\05_已知问题.md`。
> 建议打开：玩家 Combo Input Buffer、Player Charge System、Player Command Router、Attack Timeline Runner 上的 Verbose Log。

基线：2026 年 11 月 16 日，试验版分支（分支名、提交号由用户补）。结果：除 I1（宝石，暂不测）外全部为 1。
基线之后规则有两处按用户意见改了，对应的行已更新预期并标「待重测」：E2、G7、G8，另新增 G12。
下面「结果」列保留的是基线结果；每个整改批次重跑后可以在后面追加一列。

正式版整改（2026 年 11 月 16 日完成）期间，用户每批改完后做了抽测，均未发现问题，但没有逐行重填本表。
整改中新增 / 改动的规则见最后的 J 组（结果列留空，下次全量回归时填）。E2、G7、G8、G12、G13 仍标「待重测」。
逐帧核对的办法：打完一段后按 F5 暂停，用 F6~F9 往回翻（见说明书 6.4）。
