# 零碎想法（用户说过「之后再说」的）

- **连射子弹的出生点锁定**（2026-11-21）：ComboNode 关掉 `Recompute Aim Per Shot` 后，一轮连射的方向锁定为第一发（已确认有效，用户决定先保持现状）。但子弹出生点仍是枪口 `firePoint`，角色中途转身后，后几发会从角色另一侧冒出再往原方向飞。方案：第一发时记下枪口相对角色的偏移，后几发按这个偏移出生（只在方向锁定时这样做）。`Recompute Aim Per Shot` 字段要保留，用户以后要把鼠标瞄准连射加回来。
- **特效表支持「预制体 / Sprite / 动画」三选一**（2026-11-20 前后提过）：现在 EffectManager 只接预制体。用户说之后再说。
- **把特效表从场景物体搬到一个 ScriptableObject 资产里**：这样运行中调的参数退出 Play 后不会丢（现在 EffectManager 在场景里，运行时改的值退出就还原）。只是提议，用户没要求。
- **定点爆炸弹**（2026-11-21）：子弹飞到某个点（或某个时间）就爆开，造成范围伤害 / 散出小弹。
- **屏幕边缘反弹弹**（2026-11-21）：子弹碰到屏幕边缘时反弹，而不是出界回收（可用 `ScreenBounds` 判断）。
