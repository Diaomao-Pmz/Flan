## 想要的效果
- 像玩家的 ComboNode 一样：Boss 的招式卡打开后先选「这是什么类型」——近战 / 远程（弹幕）/ 特殊近战 / 特殊远程 / 传送（以后还有冲刺），
  再显示这个类型对应的参数表，外加一组所有招式通用的配置（权重、冷却、射程、理想距离、击退、动画名等）。
- Inspector 按类型、按开关隐藏用不上的栏位（和玩家那边的规矩一样：隐藏 ≠ 不生效，提示里讲清楚）。

## 现状
- Boss 招式是 `ActionNode` 派生出的几种 SO：`BulletNode / MeleeNode / DashAttackNode / LaserNode / TeleportNode`，每种一个资产类型、一个执行器（`BAE_*`，按卡类型查表派发）。
- 玩家这边的做法：一个 `ComboNode` + `moveType` 下拉 + `[SerializeReference]` 特殊招插槽 + 自定义 Inspector（`ComboNodeClashBoxEditor`）。

## 追加：AI 配置总表（11-25 用户提出，放在这一条里，不另开文件）

### 想要的效果
- 把 `BossAIDecider` 上的配置内容单独做成一个**数据资产（ScriptableObject）**，参考玩家的节拍总表 `AttackTimingConfig`。用户说这样配 Boss 招式时会好用很多。
- **AI 配置总表 ↔ 招式卡互相点击跳转**，和节拍总表 ↔ ComboNode 一样：
  - 表里每个用到卡的条目旁有「打开招式」按钮；
  - 招式卡顶上有「在 AI 配置表中打开」按钮，跳过去后只显示用到这张卡的条目，顶上有「显示全部」。

### 现状（11-25 读代码核对）
- `BossAIDecider` 是挂在 Boss 物体上的组件，配置直接存在**场景**里（Boss 不是预制体）。`Boss_Melee.unity` 是用户在用的那份；`Boss.unity` 和 `Boss_Range.unity` 的 Boss 数据是旧版（两个文件一模一样，没有规则表 / 反应池，加载时用代码默认值）。
- 要搬的配置（都只在 `BossAIDecider.cs` 内部用，别的脚本只调它的方法，所以搬家只动这一个文件 + 编辑器）：
  - 单招池 ×8：一 / 二阶段 × 弹幕 / 近战 / 特殊远程 / 特殊近战（条目 = 阶段标签 + 卡 + 情境加成）
  - 套路池 ×2（条目 = 套路 + 情境加成）、`singleInterleaveChance`
  - 位移卡池 ×2（条目 = 阶段标签、触发、差距上下限、权重、概率、卡）
  - 近身反应池 ×2（条目 = 阶段标签、条件、权重、概率、卡）、`reactionCooldown`
  - 姿态倾向 `rangedModeWeights / meleeModeWeights`、节奏 `rangedTempo / meleeTempo`、`fallbackNode`、规则表 `barrageRules`
- 节拍总表的跳转做法（参考）：`AttackTimingConfigEditor.OpenFor(node)` 设一个静态的 `FocusNode` 再 `Selection.activeObject = 表`；离开表（`OnDisable`）恢复显示全部；表用静态 `Active` 找（编辑器里没进游戏时自动找工程里第一张）。

### 和玩家节拍总表不一样的地方（设计时要注意）
- **同一张卡出现在多个条目里是正常的**（一阶段、二阶段池都放；既在单招池又在反应池），不能照搬「重复 → 报错」的规矩。
- 一张卡可能被**多张 AI 配置表**用到（以后多个 Boss）：卡上的按钮要能列出所有用到它的表；卡还可能只出现在**套路**里（套路是另一种资产），跳转时要不要把「被哪些套路用到」也列出来，待定。
- 数据资产里**不能放场景里的东西**（Transform 等），所以传送点、玩家引用这些仍留在组件上。
- 搬家要有**一次性迁移**：组件上的旧字段先隐藏保留，点按钮生成表资产并把旧值搬过去（每个场景各点一次），确认后再删旧字段。

### 开工前要和用户定的
1. 招式卡上的 AI 参数（权重、冷却、射程、理想距离、`whileBarrage`）要不要像节拍总表那样**搬进 AI 配置表**、卡上只读。这正是本文件「每个参数属于哪一级」的问题，和面板架构一起定。
2. `BAE_Teleporter` 上的**受击传送列表** `hitReactions`（本质也是一个卡池）要不要一起搬进表。
3. `BossState` 的护盾 / 眩晕 / 二阶段阈值等 Boss 身上的数值要不要也进表（变成「一个 Boss 一张总表」）。
4. 读盘时发现：`Boss_Melee` 的二阶段位移卡池 4 个条目的 Weight、Chance、Max Gap 都是 0（Unity 新加条目是 0 的坑），二阶段这些位移卡不会触发。需要跟用户确认是不是有意的。
