# 破盾值：每招单独填（B 方案）

> 提出：2026-11-21 晚。用户在 A / B / C 三个方案里选了 B，说「以后我们就按 B 方案改」。开工前照规矩先讲功能、等确认。

## 现状
- 伤害链路：玩家招式 / 子弹 / 激光 → `DamageInfo.amount` → `BossController.TakeDamage` → `BossState.bossMechanic.TakeDamage(amount, type)`。
- **护盾在时不看 amount**：近战每次命中固定扣 `meleeShieldDamage`（100），远程每次扣 `rangedShieldDamage`（3），盾 `shieldMaxHP` 300。
- 破盾后按 amount 扣 `BossState.health`。
- 副作用：多段判定每段都扣 100（三段判定一招破盾）；激光每跳都算一次远程命中。

## B 方案要做的
- 玩家这边：ComboNode（近战判定窗口 / 招式整体）、子弹、激光都能填「破盾值」，和伤害分开。
- `DamageInfo` 加一个破盾值字段（可选参数，默认「没填」）。
- `BossMechanic.TakeDamage`：收到的破盾值填了就用它，没填就按现在的近战 100 / 远程 3（**保证现有手感不变**）。
- 这一步要改 Boss 侧的 `BossState.cs`（`BossMechanic`）和 `BossController.cs`（有 BOM）。
