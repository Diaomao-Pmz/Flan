# 突进斩（DashAttack）扩展成「冲撞类技能」

> 提出：2026-11-25（11-22 讨论面板时用户也提过一次「把突进斩扩展成冲撞类技能」）。用户说以后真想改再做，先记下来。

## 想要的效果
- 现在的突进斩：冲向玩家，**到玩家面前就停**，再接挥砍。
- 用户想要的：Boss **直线冲撞一段距离**（不是冲到玩家面前就停），表现上更像 rush，而不是 dash 那种滑行。之后会改它的 Inspector 参数。
- 用户觉得名字 `DashAttacker` 不贴切，更像 rush attacker。改不改名待定。

## 现状（11-25 读代码核对）
- 执行器 `BAE_DashAttacker`（`Boss/BossLogic/Execution/Special_Melee/`）**只认领 `DashAttackNode` 一种卡**。
- 工程里只有**一张**突进斩卡 `DashAttack.asset`（`Boss/2_DataAssets/BossSkillNode/Sp_M_Node/`），只被 `Test` 套路用到；三个测试场景的单招池里都没有它。
- 冲刺段：起冲时锁定方向，按 `dashSpeed` 跑；四个停止条件 = 离玩家够近（`EffectiveStopDistance`，默认按第一段挥砍判定框自动算）/ 冲够 `maxDashDistance` / 撞墙 / 超时。冲刺段**没有伤害判定**，伤害全在后面的挥砍。
- 挥砍段：和近战卡共用 `MeleeSwing` 数据结构和 `MeleeSwingRunner`（含拼刀检查、击退）。

## 改的时候会波及的地方
1. **只改冲刺段**（停止条件、速度 → 距离 + 时长、冲撞判定）：只动 `DashAttackNode.cs` + `BAE_DashAttacker.cs`，不影响别的招。
2. **动 `MeleeSwing` / `MeleeSwingRunner`**：会影响所有近战卡（`KB_*`），要避开或单独确认。
3. **冲撞本身带伤害**：要在冲刺段新加判定（现在没有），还要定：玩家能不能拼刀 / 打断冲撞段（打断看 `BossController.CategoryOf`，现在突进斩 = SpecialMelee）。
4. **冲过玩家**：要处理和玩家身体的碰撞（穿过 / 撞停 / 推开），可以参考冲刺卡的穿身和 `BossDashEndpointGuard`（都是 Boss 侧代码，可以借）。
5. **AI 的射程 / 理想距离**：「冲到面前就停」改成「冲固定距离」后，射程的含义会变，自动停距（按判定框算）可能不再需要。
6. **改类名**（例如 `RushAttackNode` / `BAE_RushAttacker`）：要在 Unity 里连文件一起改名，保住 meta 的 guid，否则卡资产和场景里的组件会丢脚本；还要同步 `BossController.CategoryOf`、`BossAIDecider` 规则表的判断和提示文字。玩家那边的 `ActionCategory.SpecialMelee` 只是类别名，不用改。
7. **旧数值**：参数改名或删掉的话，`DashAttack.asset` 要重配（只有一张，代价小）。

## 开工时要定的
- 冲撞段打不打人、打到玩家后是继续冲还是停下接挥砍。
- 冲撞结束后还接不接挥砍（变成可选？）。
- 改不改名。
- 和 05 的「招式类型」一起想：它算特殊近战的一种，还是单独的「冲撞」类型。
