## Boss（`Enemies/Boss/`）—— 索引

黑板（`BossState`）+ 状态机（Move / Combat / Stun）+ 大脑（`BossAIDecider`，意图 + 加权抽卡 + 套路）+ 执行器（`BAE_*`，按卡类型字典查表派发）。
招式全部是 `ActionNode` 派生的 ScriptableObject 卡：`BulletNode / MeleeNode / DashAttackNode / LaserNode / TeleportNode`，套路是 `BossRoutine`。
弹幕图案在 `DataAssets/BulletNode/PatternScripts/`（10 种，`[SerializeReference]` 下拉选）。
**全部细节、加招流程、调试方法 → `Boss系统说明书.md`。**

## 公共核心（`Core/`）

- `ObjectPool/ObjectPoolManager.cs` + `PooledObject.cs`：零分配对象池，回收一律 `Recycle(gameObject)`（不传 key），重复回收是安全空操作。
- `Singleton/Singleton.cs`：派生类的 `Awake` 必须 `protected override` 并调 `base.Awake()`。
- `Combat/DamageInfo.cs`：`readonly struct DamageInfo`（amount、type、sourcePosition、instigator、breakMask、reaction、reactionParam、overrideKnockback、knockbackForce）+ `IDamageable.TakeDamage(in DamageInfo)`。
- `ScreenBounds.cs`：每帧算一次相机边界，子弹出界判断用它（`margin` 是屏幕比例，不是世界单位）。

## 其他

- `GM/`：调试控制台，`GMRegistry` 用反射收集 `[GMCommand]` 方法。
- `Items/Bullets/`：`Enemy_Projectile`（池化，`SetLifetime/SetScale/SetKnockback`）、`Player_Projectile`（已池化）、`Player_HomingProjectile`、`BulletAcceleration`（常驻组件 + `Configure()`）、`BulletComponents/BulletSineWave`。

## 代码规范（从历次重构总结）

1. **伤害**：任何伤害来源都构造 `DamageInfo` 调 `IDamageable.TakeDamage`；要加维度就往 `DamageInfo` 加字段，不开新重载。
2. **对象池**：归还只用 `Recycle(gameObject)`；把池化对象挂到父物体下时，父物体销毁前必须先归还子物体。
3. **高频对象上的组件**常驻 + 开关控制，禁止运行时 `AddComponent` / `Destroy(Component)`。
4. **ScriptableObject 运行时只读**：计时器、CD 等运行时状态放在 MonoBehaviour / 运行时类里。
5. **输入**只在 `PlayerController`；**动画播放**只在 `PlayerAnimationDriver`；**日志**用 `PlayerLog`，不留裸 `Debug.Log`（尤其热路径）。
6. **动画事件不能是唯一生命线**：靠动画事件退出的逻辑必须有兜底超时。
7. Boss 执行器必须实现可重入的 `Cancel()`；协程里用 `yield return executor.Execute(...)`，不要 `StartCoroutine` 派生子协程。
8. 远程攻击瞄 `ctx.PlayerAimPoint`，不要用 `player.position`（玩家轴心在脚底）。
9. 代码注释用中文，惯用"【批次X 改动】+ 症状 / 根因 / 比喻"的格式记录改动原因。
