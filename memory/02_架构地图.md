## Boss（`Boss/Boss/` 脚本，`Boss/1_DataAssets/` 招式卡）—— 索引

黑板（`BossState`）+ 状态机（Move / Combat / Knockback / Stun）+ 大脑（`BossAIDecider`：意图 + 加权抽卡 + 套路 + 位移卡池 + 近身反应 + 规则表）+ 执行器（`BAE_*`，按卡类型字典查表派发）。
招式全部是 `ActionNode` 派生的 ScriptableObject 卡：`BulletNode / MeleeNode / DashAttackNode / LaserNode / TeleportNode / DashMoveNode`，套路是 `BossRoutine`。弹幕图案在 `Boss/1_DataAssets/BulletNode/PatternScripts/`（10 种，`[SerializeReference]` 下拉选）。

| 模块 | 关键文件 | 一句话 |

**两层的说法（11-22 和用户对齐的）**：身体层 = Boss 身体此刻正在做的那一招（`CombatState.CurrentAction`，站着放的弹幕也算），玩家打断只打它；弹幕层 = 已经交给发射器自己发完、不占身体的弹幕。破盾 / 转阶段 / 死亡两层全停。子弹永远由发射器发，从哪发出看「跟不跟随 Boss」。

**一招弹幕的完整流程（第 4 阶段之后）**：`SelectSkill` → `ResolveFireMove / ResolveRelease / ResolveReaction` 读卡和步骤 → `Execute`（站着放，开火时移动）→ 每帧：到脱手时间就 `TryRelease`（脱手）；允许近身反应时 `TryStartReaction`（托管 → 反应招 → 取回接着放 / 直接下一步）→ `Finish`：脱手过的把「脱手时间 + 能不能冲刺」交给 MoveState（`ArmAfterRelease`），套路能马上接就留在 CombatState。

**受击**（11-21）：`BossController.TakeDamage` → `HandleBreakAndKnockback`：正在出招且 `breakMask` 含这一招的类别（`CategoryOf`：MeleeNode = Melee，BulletNode = Bullet，DashAttackNode = SpecialMelee，LaserNode = SpecialBullet，TeleportNode = Teleport，其余（含 DashMoveNode）= None 打不断）→ 打断（AI `ClearIntent`，套路作废）；有击退距离 / 硬直且（没在出招或被打断）→ `BossKnockbackState`。护盾：`DamageInfo.shieldDamage` 填了就按它扣（11-22 破盾值），-1 按老规矩近战 100 / 远程 3；破盾后才按 `amount` 扣 `BossState.health`。持续推力 `HandlePush / TickPush`（玩家激光用）。`BossController` 从 `EntityBase` 继承的 Max HP 不用。

## 公共核心（`Core/`）

- `ObjectPool/ObjectPoolManager.cs` + `PooledObject.cs`：零分配对象池，回收一律 `Recycle(gameObject)`（不传 key），重复回收是安全空操作。`PooledObject.BorrowId` 每借出一次 +1：想"晚点再回收自己借的东西"时先记下它，回收前核对没变。
- `Singleton/Singleton.cs`：派生类的 `Awake` 必须 `protected override` 并调 `base.Awake()`。
- `Combat/DamageInfo.cs`：`readonly struct DamageInfo`（amount、type、sourcePosition、instigator、breakMask、reaction、reactionParam、overrideKnockback、knockbackForce、hitStun、**pushSpeed、pushDuration**（持续推力，可选）、**shieldDamage**（11-22 破盾值，-1 = 按老规矩））。攻击方只表达意图，受击方自己决定怎么反应+ `IDamageable.TakeDamage(in DamageInfo)`。
- `ScreenBounds.cs`：每帧算一次相机边界，子弹出界判断用它（`margin` 是屏幕比例，不是世界单位）。

## 其他

- `GM/`：调试控制台，`GMRegistry` 用反射收集 `[GMCommand]` 方法。
- `Items/Bullets/`：`Enemy_Projectile`（池化，`SetLifetime/SetScale/SetKnockback`）、`Player_Projectile`（已池化；重力固定 0；带消弹时每个物理帧扫一遍路径上的敌弹；`Configure` 调速度 / 体积，`SetDamage` 设本发伤害，回池全部还原）、`Player_HomingProjectile`、`BulletAcceleration`（常驻组件 + `Configure()`）、`BulletComponents/BulletSineWave`。

## 代码规范（从历次重构总结）

1. **伤害**：任何伤害来源都构造 `DamageInfo` 调 `IDamageable.TakeDamage`；要加维度就往 `DamageInfo` 加字段，不开新重载。
2. **对象池**：归还只用 `Recycle(gameObject)`；把池化对象挂到父物体下时，父物体销毁前必须先归还子物体。
3. **高频对象上的组件**常驻 + 开关控制，禁止运行时 `AddComponent` / `Destroy(Component)`。（注意：MonoBehaviour 的类名必须和文件名一致，否则编辑器里挂不上，只能代码补挂。）
4. **ScriptableObject 运行时只读**：计时器、CD 等运行时状态放在 MonoBehaviour / 运行时类里。
5. **输入**只在 `PlayerController`；**动画播放**只在 `PlayerAnimationDriver`；**日志**用 `PlayerLog`，不留裸 `Debug.Log`（尤其热路径）。
6. **动画事件不能是唯一生命线**：靠动画事件退出的逻辑必须有兜底超时。
7. Boss 执行器必须实现可重入的 `Cancel()`；协程里用 `yield return executor.Execute(...)`，不要 `StartCoroutine` 派生子协程。
8. 远程攻击瞄 `ctx.PlayerAimPoint`，不要用 `player.position`（玩家轴心在脚底）。
9. 代码注释用中文，**脚本里只写和代码直接相关的注释**；设计理念、比喻、历史踩坑不写在脚本里，写进设计文档（2026-11-16 用户决定。已移出的见 `设计注释归档.md`）。修 bug 时可以留一条简短的"症状 / 根因"。
