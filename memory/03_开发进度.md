### 2026-11-21 晚　BB3 激光、招式类型、消弹、节拍总表、蓄力与跳跃手感
- **招式类型**：ComboNode 加 `moveType` 下拉（近战 / 远程 / 混合 / 特殊近战 / 特殊远程，默认混合 = 旧行为）。Inspector 按类型只显示用得上的栏位（近战藏子弹参数，远程藏伤害 / 判定框；特殊招只显示特殊招插槽 + 蓄力设定 + 打断能力 + 消弹 + 拼刀 + 子节点）。
- **特殊招式插槽**（`SpecialMove`，`[SerializeReference]`）：特殊招在下拉里选一个具体效果，参数直接在 ComboNode 上填；下拉按近战 / 远程过滤（`[SpecialMoveInfo]`）。时间表在出招时调 `Begin`、每帧 `Tick`、被打断或打完调 `End`；特殊招不走普通的出刀 / 出弹事件。
- **BB3 = 玩家激光**（`Combat/SpecialRange/LaserSpecial.cs`，**和 Boss 激光分开写**）：前摇画预警线，判定段开火，判定段结束就收；只在前摇里转向（`followMouse` + `trackTurnSpeed`）；默认被 `obstacleLayers` 里的墙截断；从指尖 `firePoint` 往前打，画法和贴图轴心无关；每跳伤害 + 跳伤间隔；**第一跳**带 breakMask / 受击反应 / 击退 / 硬直，**每一跳**都给 Boss 一个持续推力（ComboNode `bossPushSpeed`）。开火时能走，速度倍率滑条 `fireMoveFactor`：向前 ×(1−f)、向后 ×(1+f)，开火中不转身，只在地面。
- **Boss 持续推力**：`DamageInfo` 加 `pushSpeed / pushDuration`；`BossController.HandlePush / TickPush` 在位置上叠加推移（撞墙停，眩晕时不推），和击退状态互不干扰。
- **消弹**（`Combat/BulletCanceller.cs`）：ComboNode 消弹多选 `bulletCancel`：子弹（玩家子弹沿路消掉敌弹，直到打中 Boss 或飞出屏幕）、位移（出招位移期间碰到的敌弹消掉，且这段时间不吃弹伤，`PlayerState.CancelBulletsOnContact`）、近战判定（**未实现**，见待定事项）。消弹播 EffectManager 的「消弹」特效（`EffectUsage.BulletCancel`）。
- **节拍总表**：每行标题旁加招式选框，**不再按名字自动绑定**（只在 Reset 时按名字找一次）；同一招被拖进两行 → 报错、两行都不生效。新字段：判定开始时间 `hitboxStartTime`、出弹时间 `projectileStartTime`、特效时间 `playEffectTime`（都从动画 0 点算，-1 = 跟动画事件）；按招式类型分「判定 / 出弹」组，另分「动画」「表现」两组；时间超出阶段会提示。
- **新动画事件 `MarkAttackBegin`**：只标记「前摇结束」，不出判定（判定改由表里的时间出）。`hitboxDuration = -1` = 一直开到判定段结束。
- **蓄力**：起蓄时间按招配置（`comboChargeStartTime`，找不到招时用旧的全局值并在 Console 警告）；`chargeAllowedFrom` 下拉决定前一招的哪个阶段起就能开始蓄（后摇结束 / 后摇开始 / 判定开始，默认后摇结束）；蓄力减速改成「起始值 → 终值」渐变（移速、跳跃各一对），渐变时长 `chargeSlowRampTime`，-1 = 跟起蓄时间。
- **双蓄配方**：两边类型 + 等级 → 只看等级总和（滑条 2～6），旧字段隐藏并自动迁移；WeaponLoadout 里总和重复会报错。
- **跳跃手感**：改成填高度：`maxJumpHeight`（2.87，和原手感一样）、`minJumpHeight`（点按至少跳多高）、`minJumpVelocity`（松手后剩下的上升速度）、`fallGravityMultiplier`（下落加重力，默认 1 = 不变）。起跳速度 = √(2g·最大高度)。注：最小高度实际下限由「点按最短多久」决定（起跳速度 13 时一个物理帧就升 0.26），所以填 0.1 和 0.3 差别不大。
- **玩家子弹不再下坠**：`Player_Projectile` 的 Awake 里把重力设为 0（P_Bullet 预制体上是 1）。
