## 踩坑备忘（Unity 相关）

- **MonoBehaviour 类名必须和文件名一致**，否则 Add Component 里搜不到（`AttackTimelineRunner` 曾写在 `AttackTimeline.cs` 里，只能靠运行时补挂）。
- **删"兜底"之前先确认它确实不再被触发**：曾根据回归清单的结果推断 prefab 已挂组件，删掉运行时补挂后整套攻击 / 冲刺 / 滑铲空引用。
- 改 SO 字段名时加 `[FormerlySerializedAs("旧名")]`，已配置的值才不会丢。

- Unity 只调用最派生类上的 `Awake`：基类 `Awake` 必须 `protected virtual`，派生类 `override` 并调用 `base.Awake()`。
- `Destroy(Component)` 延迟到帧末才执行，池化对象同帧重新借出会拿到"脏"组件。
- `Start()` 一生只跑一次：池化对象的初始化放 `Configure()` / `OnSpawn`，不要放 `Start()`。
- SO 资产运行时写字段：编辑器里会污染资产，打包后所有实例共享。
- `BulletAcceleration` 必须手动挂在 `EnemyBullet` 预制体上，否则加速弹失效。
