# 01 项目概览

> 最后核对：2026-11-20（对照 `main` 分支提交 `4fde733` 的文件）

## 基本信息

- **类型**：2D 动作平台游戏（近战连招 + 远程射击 + 飞行 + Boss 弹幕战）
- **主角**：芙兰（Flandre），代码命名空间 `Flandre.CombatSystem`
- **引擎**：Unity `6000.3.1f1`
- **规模**：约 146 个 C# 脚本、约 2 万行（玩家约 1.15 万行，Boss/敌人约 5.5 千行）
- **仓库**：`https://github.com/Diaomao-Pmz/Flan`，本地 `D:\Unity project\Flan`

## 主要包

| 包 | 版本 | 用途 |
|---|---|---|
| URP (`render-pipelines.universal`) | 17.3.0 | 2D 渲染管线 |
| Input System | 1.17.0 | 输入（只允许 `PlayerController.cs` 直接碰） |
| Cinemachine | 3.1.6 | 镜头 |
| 2D Animation / Aseprite / PSD Importer / Tilemap Extras / Pixel Perfect | — | 美术管线 |
| TextMesh Pro（含中文字体 NotoSansSC，已加到 TMP 全局 Fallback） | — | 文字 |

> Package Manager 里 Burst、Collections、Timeline 等官方包显示「Invalid signature」：Unity 6.3 起的签名检查的已知问题，不影响编译和运行，**不要按提示删包**。见 `05_已知问题.md`。

## 文件夹结构（`Assets/`）

```
Assets/
├── Scripts/
│   ├── Player_V0.2/        ← 当前玩家代码（主力，见 02 架构地图）
│   │   ├── 1_Config/       ← 配置 SO：P_Animation（节拍总表）/ P_BUFF / P_Combat / P_Movement / P_State
│   │   ├── Editor/         ← 节拍总表、特效表的自定义 Inspector
│   │   └── Animaion/ Combat/ Core/ Data/ FSM/ Gem/ Input/
│   ├── Player_Old/ Player_V0.1/  ← 空文件夹（旧版已移除）
│   ├── Enemies/Boss/       ← Boss 系统（详见 Boss系统说明书.md）
│   ├── Items/Bullets/      ← 玩家 / 敌人子弹、子弹组件
│   ├── Items/Objects/      ← 关卡物件：书、宝箱、传送门、单向平台、陷阱平台
│   ├── Core/               ← 对象池、单例、伤害契约 DamageInfo、ScreenBounds

│   ├── SkillTree/          ← 技能树（早期，规模小）
│   ├── Cinemachine/        ← 镜头切换触发器、镜头序列
│   ├── MathHelper/
│   ├── UpdateLog/          ← 重构说明文档
│   └── Readme.md           ← 英文项目简介（四大架构亮点）
├── GM/                     ← GM 调试控制台 / 面板（GMRegistry 反射注册命令）
├── IA/                     ← InputActions 资产；IA/Prefabs/Player.prefab 是玩家预制体
├── Scenes/
│   ├── SampleScene.unity
│   ├── Test/Boss.unity, Test/Player.unity
│   └── Tutorial/Tutorial_Level.unity, Tutorial_Level-Skill Tree Test.unity
├── Animations/  Sprites/  Tiles/  Material/  Settings/
└── All-Chinese-Character-Set-main/   ← 第三方中文字符集（用于生成 TMP 字体）
```

项目根目录（`Assets/` 之外）：
- `memory/`：本记忆库。
- `Claude outputs/`：给用户看的设计文档（`芙兰战斗系统说明书_v5.docx`、`设计注释归档.md`）。
