一、战斗操作
1.平a          
近/远 = 鼠标左/右键

*近远平a各三段，在后摇时可以换手(eg: 原本左键下次按右键)更快打出下一发平a
==========================================
2.蓄力        
近/远 = 鼠标左/右键 长按
总共三级，原地蓄力：0->1级，n段平a后蓄力：0->n级

*蓄的再久也不能提升等级，得按下蓄力升级按键，见3
*平a后接的那一下蓄力更快
*蓄力时只是蓄力手不能攻击，另一只手仍可以攻击
*蓄力打出后，平a连段深度继承自上一次平a的深度（eg：（字母意思看5）A1，再蓄力打出AA2。下一发平a可以是A2/B2，但不是A3/B3）
*双蓄力会有特殊效果，见4
==========================================
3.蓄力升级 
近/远 = 鼠标前/后侧键

*蓄力升级不接受平a后的蓄力加速
==========================================
4.双蓄力
两只手同时蓄力，前摇后释放只因⭐光

*双手蓄力的总段数决定释放时间长短
==========================================
5.蓄力招式说明
XXn（X=A/B，A代表近战，B代表远程 // n = 1/2/3，表示招式深度，即1，2，3段）
AA1/BB1    拼刀
*均为短暂前摇后判定拼刀，成功后可以使boss短暂眩晕，但不会打断连招
AA2/BB2   消弹
*前者是突刺，后者是后撤射击。前者在位移过程中均可消单，后者的dark弹van会抵消所有碰到的弹幕
AA3/BB3   伤害+打断
*前者为蓄力后突进斩击，后者为蓄力后后撤射击。二者均可以打断boss当前招式，并且可以拼刀，但是没有消弹能力

二、位移操作（awsd，space跳过）
1.冲刺              shift
冲刺。cd较快，距离较短，没有无敌帧
==========================================
2.滑铲              方向键+ctrl
滑铲。cd较长，但是有无敌帧

*空中按ctrl，下落全程有无敌帧，且可以加速下坠
==========================================
3.飞行              左alt
消耗mp变成小蝙蝠🦇

*蓄力时可以飞行，不打断蓄力。但飞行时不可蓄力
*建议先按alt再按方向键，unity快捷键有bug我取消不掉...
